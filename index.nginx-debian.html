● 0 Cookies / 0 Telemetry

2. Cookies & Tracking Technologies

We do not use tracking cookies, analytics services (e.g. Google Analytics), advertising networks, or fingerprinting scripts. All fonts and assets are hosted locally on our own server to prevent unauthorized third-party data transfers.

3. Server Logs & Processing (Art. 6(1)(f) GDPR)

When you visit this website or connect to our dedicated game server instances, standard technical connection metadata is temporarily processed in local server log files (such as IP address, date/time stamp, requested resource, and user-agent). This processing is strictly necessary for legitimate interests to ensure network security, prevent DDoS abuse, and maintain service stability. Log entries are automatically purged after 14 days.
