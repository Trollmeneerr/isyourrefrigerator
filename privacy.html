GDPR COMPLIANCE & HOSTING

Privacy & Hosting Policy

Transparency, user privacy, and homelab integrity are central to everything hosted on IsYourRefrigerator.online.

01

GDPR Compliance

We fully comply with the European Union General Data Protection Regulation (GDPR). As a personal homelab project hosted in Europe, we strictly limit data processing to what is strictly necessary to run game freezers. We never sell, monetize, or profile user data.

02

Zero Website Logs & No Tracking

This website operates with a strict Zero Logs policy. We do not store web visitor access logs, browser fingerprints, or IP addresses. We do not use tracking cookies, Google Analytics, or third-party ad networks.

03

Game Server Logs (30-Day Retention)

Dedicated game servers (such as Minecraft, Project Zomboid, Valheim, and The Forest) generate internal technical logs (e.g. console errors, player connect/disconnect events, and crash dumps). These logs are kept for a maximum of 30 days solely to monitor server health and check if any technical issues or crashes occur inside the game servers. Logs older than 30 days are automatically purged.

04

Homelab Hosting Terms

Freezer hosting is hosted with love for friends and community experiments. Fair resource usage is requested so the refrigerator stays online for everyone. No user data is sold, monetized, or shared with third parties.
